# Unicorn Arcade 0.6.0 alpha

This build replaces the six reused companion-room backgrounds with newly authored production environment art and restores the original React room interaction model: original transparent decor artwork, contextual item controls, and a categorized three-column furniture bag bottom sheet. Galaxy Unicorn now begins with slow enemies and increases movement speed smoothly by level.

All scenes now respect a global phone safe area. Unicorn Alley has a new unified pastel town plate with six room-themed doors and matching door-shaped navigation targets.

Validation target: 75 deterministic parity checks plus the runtime integration suite, phone-sized captures for the room and furniture bag, and a debug-signed arm64 Android export.
