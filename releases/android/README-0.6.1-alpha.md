# Unicorn Arcade 0.6.1 alpha

This is the upgrade-compatible rebuild of the production-room checkpoint. It uses version code 10 and the same debug signing certificate as every working Unicorn Arcade build from 0.1.0 through 0.5.0, so Android can install it directly over 0.5.0.

Certificate SHA-256: `97dcac80c34ab36c9b1e0da8cef5dc87c14911ffdb26d30aa0bc039f1e8be42b`

Included gameplay and presentation changes:

- Six newly authored production companion-room environments.
- Transparent illustrated furniture assets, contextual editing controls, and the visual furniture-bag bottom sheet.
- Global phone safe-area handling for notches and camera cutouts.
- A unified pastel Unicorn Alley with six themed doors and aligned door-shaped controls.
- Galaxy Unicorn enemies start slowly and accelerate by level.
