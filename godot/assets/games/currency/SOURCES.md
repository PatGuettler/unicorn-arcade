# US currency learning assets

These raster assets were restored from the original Unicorn Arcade source tree in
`src/components/assets`. They depict recognizable current United States currency
and are used only inside the Coin Count and Cash Counter educational activities.

| Game asset | Original source filename | Denomination |
| --- | --- | --- |
| `penny.png` | `penny.png` | 1 cent |
| `nickel.png` | `nickle.png` | 5 cents |
| `dime.png` | `dime.png` | 10 cents |
| `quarter.png` | `quarter.png` | 25 cents |
| `one_dollar.jpg` | `oneDollar.jpg` | $1 |
| `five_dollar.png` | `fiveDollar.png` | $5 |
| `ten_dollar.png` | `tenDollar.png` | $10 |
| `twenty_dollar.jpg` | `twentyDollar.jpg` | $20 |
| `fifty_dollar.png` | `fiftyDollar1.png` | $50 |
| `one_hundred_dollar.png` | `hundoDollar.png` | $100 |

Before a public-store release, re-audit the presentation against the current
[Bureau of Engraving and Printing currency image rules](https://www.bep.gov/currency/currency-image-use)
and [United States Mint image-library policy](https://www.usmint.gov/news/image-library).
The images must not be recolored or presented as spendable digital currency.
